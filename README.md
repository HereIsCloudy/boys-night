# Storage Hunters 3D Builder

This repository is a browser-based 3D storage layout builder inspired by warehouse-style placement and game-building mechanics.

## Files

- `index.html` — Interactive homepage and 3D builder interface.
- `style.css` — Responsive visual layout for the builder UI.
- `app.js` — Three.js scene, placement tools, automatic layout, and export logic.

## Usage

Open `index.html` in your browser or visit the GitHub Pages site to use the interactive builder. The page runs entirely in the browser and requires no server setup.

Use the sidebar controls to adjust the grid size, choose tools, place walls, shelves, doors, and walkways, or auto-generate a layout.

### Controls

- `Apply size` — Resize the grid to the chosen dimensions.
- `Auto layout` — Fill the grid automatically with perimeter walls, doors, shelves, and walkways.
- `Reset` — Return the builder to the default 12×18 layout.

## Notes

The repository no longer includes the older Python CLI generator. The focus is now on a polished browser-based 3D builder experience.
