How to use

Select a tool, then click any grid cell to place or remove an object. Use the camera controls to orbit and zoom.

Doors are best placed on outer walls, shelves can be stacked along the interior, and walkways are shown as floor tiles.

This page is a 3D browser-based builder inspired by open-world storage shop and garage layout tools. It runs entirely in your browser and can be deployed on GitHub Pages.
