Layout Generator

This repository now hosts a Python CLI project that generates an optimized ASCII layout blueprint for rectangular grids using rules and a build catalog.

Use the Python script directly from the repository, or inspect the configuration files for customization.

  • README — Project instructions and usage examples.
  • generate_layout.py — Python CLI generator.
  • rules.json — Default layout rules and grid settings.
  • catalog.json — Default item cost catalog.

Run locally with:

python generate_layout.py
